1: SALES DATA ANALYSIS
============================================================


AIM To perform sales data analysis using Pandas, NumPy and Matplotlib,
including reading, combining, cleaning, analysing and visualizing sales
data stored in different file formats.

KEY CONCEPTS - Pandas is used for data manipulation and analysis. -
NumPy is used for numerical operations. - Matplotlib is used to create
graphs. - A DataFrame is a two-dimensional table containing rows and
columns. - CSV, Excel and JSON are common data storage formats. - Data
cleaning includes handling missing values, duplicates, spaces and
incorrect data types. - groupby() groups records and allows calculations
such as sum and mean. - concat() combines DataFrames. - describe() gives
descriptive statistics.


VIVA AND CODE QUESTIONS

Q1. What is Pandas? A. Pandas is a Python library used for data
manipulation, cleaning and analysis.

Q2. What is NumPy? A. NumPy is a Python library used for numerical
calculations and array operations.

Q3. What is Matplotlib? A. Matplotlib is a Python library used to create
graphs and visualizations.

Q4. What is a DataFrame? A. A DataFrame is a two-dimensional tabular
data structure with rows and columns.

Q5. What is the aim of this practical? A. To load sales data, split it
into parts, save it in CSV, Excel and JSON formats, read and combine the
files, clean the data, analyse sales and visualize the results.

Q6. What does read_csv() do? A. It reads a CSV file and creates a Pandas
DataFrame.

Q7. What is the difference between read_csv() and to_csv()? A.
read_csv() reads a CSV file into a DataFrame. to_csv() saves a DataFrame
into a CSV file.

Q8. What are CSV, Excel and JSON? A. CSV stores tabular data as
comma-separated text. Excel stores spreadsheet data. JSON stores
structured data as key-value pairs and records.

Q9. What does head() do? A. It displays the first five rows by default.

Q10. What does shape return? A. It returns a tuple containing the number
of rows and columns.

Q11. What does info() display? A. It displays column names, data types,
non-null counts and memory usage.

such as count, mean, standard deviation, minimum, maximum and quartiles.

Q13. What does isnull().sum() do? A. It counts the missing values in
each column.

the DataFrame.

Q15. What does drop_duplicates() do? A. It removes duplicate records.

Q16. What does iloc[] do? A. It selects rows or columns using integer
positions.

Q17. What is the difference between loc[] and iloc[]? A. loc[] selects
using labels; iloc[] selects using integer positions.

Q18. What does pd.concat() do? A. It combines two or more DataFrames
along rows or columns.

Q19. What is the difference between concat() and merge()? A. concat()
joins DataFrames along an axis. merge() combines DataFrames using common
columns or keys, similar to a database join.

Q20. What does ignore_index=True mean? A. It creates a new continuous
index after combining the DataFrames.

Q21. What does index=False mean in to_csv()? A. It prevents the
DataFrame index from being written as an extra column.

Q22. What does to_excel() do? A. It exports a DataFrame into an Excel

Q23. What does to_json() do? A. It exports a DataFrame into JSON format.

Q24. What does orient=“records” mean in to_json()? A. It stores each row
as a separate JSON object.

Q25. What does errors=“coerce” do in to_numeric()? A. It converts
invalid or non-numeric values into NaN.

Q26. What does to_datetime() do? A. It converts date-like values into
Pandas datetime format.

Q27. What is the difference between mean, median and mode? A. Mean is
the average, median is the middle value after sorting, and mode is the
most frequently occurring value.

Q28. Why is median often used to fill missing numerical values? A.
Median is less affected by extreme values or outliers than the mean.

Q29. What does fillna() do? A. It replaces missing values with a
specified value or calculated value.

Q30. What does groupby() do? A. It groups records based on one or more
columns so calculations can be performed for each group.

Q31. What is the difference between sum() and mean()? A. sum()
calculates the total; mean() calculates the average.

Q32. What does sort_values(ascending=False) do? A. It sorts values from
highest to lowest.

Q33. What is a bar chart used for? A. It compares values across
different categories.

Q34. What is a pie chart used for? A. It displays how each category
contributes to a whole.

Q35. What does autopct do in a pie chart? A. It displays percentage
values on the pie chart.

Q36. What is the result/conclusion of this practical? A. The sales data
is combined and cleaned, sales summaries are calculated by product line

2: WEATHER DATA ANALYSIS USING OPENWEATHERMAP API
============================================================


AIM To fetch weather forecast data using the OpenWeatherMap API, process
and analyse weather measurements, create visualizations and save the
results.

KEY CONCEPTS - An API allows two software applications to communicate. -
OpenWeatherMap API provides weather information. - requests.get() sends
an HTTP GET request. - JSON is a structured data-exchange format. - An
API key is used to authenticate access to an API. - Weather attributes
include temperature, humidity, wind speed and rainfall. - Daily
aggregation calculates summaries for each date. - Correlation measures
the relationship between numerical variables. - try-except is used to
handle errors safely.


VIVA AND CODE QUESTIONS

Q1. What is an API? A. API stands for Application Programming Interface.
It allows software applications to communicate and exchange data.

Q2. Which API is used in this practical? A. OpenWeatherMap API.

Q3. What is an API key? A. It is a unique authentication key used to
access an API service.

Q4. What is an API endpoint? A. It is a specific URL through which an
API service or resource is accessed.

Q5. Which HTTP method is used in this practical? A. GET, because the
program retrieves weather data from the server.

Q6. What is JSON? A. JSON stands for JavaScript Object Notation. It is a
lightweight format used to exchange structured data.

Q7. What does the requests library do? A. It sends HTTP requests to web
services and receives their responses.

Q8. What does requests.get() do? A. It sends an HTTP GET request to the
specified URL.

Q9. What does response.json() do? A. It converts a JSON response into
Python dictionaries and lists.

Q10. What does response.status_code represent? A. It represents the HTTP
status code returned by the server.

Q11. What does status code 200 mean? A. The request was successful.

Q12. What does status code 401 mean? A. The request is unauthorized,
often because the API key is invalid or inactive.

Q13. What does raise_for_status() do? A. It raises an HTTP error if the
response indicates an unsuccessful request.

Q14. What is the purpose of params in requests.get()? A. It contains
query parameters such as city, country, API key and units.

Q15. Why is units=“metric” used? A. It requests measurements in metric
units, including temperature in Celsius.

Q16. What does timeout=20 mean? A. The request waits for a response for
up to 20 seconds.

Q17. What does getpass() do? A. It accepts input without displaying the
typed value normally, which is useful for entering an API key.

Q18. What is humidity? A. Humidity is the amount of water vapour present
in the air, commonly expressed as a percentage.

Q19. What is wind speed? A. It measures how fast air is moving.

Q20. Why is rainfall extracted using item.get(“rain”, {}).get(“3h”, 0)?
A. Rain data may be absent from a forecast record. The nested get()
safely retrieves the three-hour rainfall value and uses zero if it is
absent.

Q21. What does pd.DataFrame(records) do? A. It converts a list of
dictionaries into a tabular DataFrame.

Q22. What does pd.to_datetime() do? A. It converts date strings into
datetime values.

Q23. What does dt.date do? A. It extracts only the date part from a
datetime value.

Q24. What is aggregation? A. Aggregation summarizes multiple records
using operations such as sum, mean, minimum, maximum or count.

Q25. Why is daily aggregation performed? A. It summarizes forecast
measurements by date, making daily trends easier to understand.

Q26. What does agg() do? A. It applies one or more aggregation functions
to grouped data.

Q27. What is correlation? A. Correlation measures the strength and
direction of the relationship between two numerical variables.

Q28. What does a correlation of +1 mean? A. It indicates a perfect
positive linear relationship.

Q29. What does a correlation of -1 mean? A. It indicates a perfect
negative linear relationship.

Q30. What does a correlation near 0 mean? A. It indicates little or no
linear relationship.

Q31. What is a heatmap? A. It is a visualization that represents
numerical values using colours.

Q32. Why can a constant column be excluded from correlation analysis? A.
A constant column has zero variance, so its correlation is undefined.

Q33. What is exception handling? A. It is a way to handle runtime errors
without abruptly terminating a program.

Q34. What is the purpose of try-except? A. try contains code that may
fail; except handles the specified error.

Q35. What is the difference between HTTPError and RequestException? A.
HTTPError represents an unsuccessful HTTP response. RequestException is
a broader class of request-related errors, including connection
problems.

Q36. What is the conclusion of this practical? A. Weather forecast data
is retrieved through an API, converted into a DataFrame, cleaned,
summarized daily, visualized and saved.


CODE-ORIENTED QUICK QUESTIONS

Q38. What does records.append() do? A. It adds a new extracted forecast

Q40. What does item[“weather”][0][“description”] access? A. It retrieves
the first weather description in the weather list.

Q41. What does fillna(0) do? A. It replaces missing values with zero.

extracts the date while removing the time component.

Q43. What does .corr() do? A. It calculates the correlation matrix for
numerical columns.

Q44. What does sns.heatmap() do? A. It creates a heatmap visualization.

Q45. What does plt.subplots(2, 2) create? A. It creates a figure
containing four plotting areas arranged in two rows and two columns.

Missing values and duplicates must be checked and handled. - Feature
engineering creates useful features from existing data. - Encoding
converts categorical values into numerical form. - X contains input
features and y contains the target. - train_test_split() divides data
into training and testing sets. - StandardScaler standardizes numerical
features. - Stratification preserves class proportions during splitting.

stops using a company’s product or service.

Q2. What is the aim of this practical? A. To clean the customer churn
dataset and prepare its features for a machine learning task.

Q3. What is data preprocessing? A. It is the process of cleaning,
transforming and preparing raw data before applying a machine learning
algorithm.

Q4. Why do we check missing values? A. Missing values can cause errors
or affect the reliability of analysis and machine learning.

column.

transforming features to make them more useful for analysis or machine
learning.

into intervals or bins.

4: DATA WRANGLING ON REAL ESTATE DATA
============================================================


AIM To perform data wrangling on Bengaluru real estate data by cleaning
the dataset, transforming property features, handling outliers, encoding
categories and analysing prices by location.

KEY CONCEPTS - Data wrangling means cleaning and transforming raw data
into a useful form. - The dataset contains property details such as
location, size, area, bathrooms and price. - BHK means bedrooms, hall
and kitchen. - Feature extraction obtains useful information from
existing columns. - Price per square foot is calculated from price and
area. - IQR is used to identify potential outliers. - Category codes and
one-hot encoding convert categories into numbers. - groupby() is used
for location-wise summaries. - Correlation heatmaps show relationships
between numerical variables.


VIVA AND CODE QUESTIONS

Q1. What is data wrangling? A. Data wrangling is the process of
cleaning, transforming and organizing raw data into a useful format.

Q2. Which dataset is used? A. The Bengaluru House Data dataset.

Q3. What information does the dataset contain? A. It contains property
information such as area type, location, size, total square feet,
bathrooms, balconies and price.

Q4. Why are duplicate records removed? A. Duplicate records can lead to
incorrect counts and biased summaries.

Q5. Why are unnecessary columns removed? A. Columns that are not needed
for the analysis can be removed to simplify the dataset.

Q6. What is BHK? A. BHK stands for Bedroom, Hall and Kitchen.

Q7. Why is BHK extracted from the size column? A. The size column
contains text such as “2 BHK” or “4 Bedroom”. Extracting the number
makes the feature suitable for numerical analysis.

Q8. What is feature extraction? A. It is the process of obtaining useful
information from existing data.

Q9. Why is total_sqft converted to numeric? A. The column may contain
ranges or text values. Numerical conversion is required to calculate
area-based measures.

Q10. How is price per square foot calculated? A. Price per square foot =
(Price in lakhs x 100000) / Total square feet.

Q11. Why is price multiplied by 100000? A. The price column is expressed
in lakhs, so multiplying by 100000 converts it into rupees.

Q12. What is an outlier? A. An outlier is a value that is unusually high
or low compared with most of the other observations.

Q13. What is IQR? A. IQR stands for Interquartile Range and is
calculated as Q3 minus Q1.

Q14. What is Q1? A. Q1 is the 25th percentile.

Q15. What is Q3? A. Q3 is the 75th percentile.

Q16. How are outlier limits calculated using IQR? A. Lower limit = Q1 -
1.5 x IQR. Upper limit = Q3 + 1.5 x IQR.

Q17. Why are outliers handled? A. Extreme values can strongly influence
averages, visualizations and some machine learning algorithms.

Q18. Does IQR prove that every flagged value is an error? A. No. It
identifies potential outliers. Domain knowledge is needed to decide
whether a value should be removed or retained.

Q19. What is categorical encoding? A. It converts category labels into
numerical representations.

Q20. What does cat.codes do? A. It assigns an integer code to each
category.

Q21. What is one-hot encoding? A. It creates a separate binary column
for each category.

Q22. What is the difference between category codes and one-hot encoding?
A. Category codes assign integer labels. One-hot encoding creates
separate 0/1 columns and does not imply an order between categories.

Q23. What does groupby(“location”) do? A. It groups property records
according to location.

Q24. What is aggregation? A. Aggregation calculates summaries such as
average price, average area and property count for each group.

Q25. Why are locations with very few properties sometimes filtered out?
A. Averages based on very few records may be less reliable.

Q26. What does sort_values(ascending=False) do? A. It sorts values from
highest to lowest.

Q27. What does reset_index() do? A. It turns the existing index into a
regular column and creates a default integer index.

Q28. What is a count plot? A. It displays the number of observations in
each category.

Q29. What is a correlation heatmap? A. It uses colours to show
correlation coefficients between numerical variables.

Q30. What is the conclusion of this practical? A. The real estate data
is cleaned and transformed, price per square foot is calculated,
potential outliers are handled, categories are encoded and location-wise
property summaries are created.


CODE-ORIENTED QUICK QUESTIONS

Q31. What does str.extract(“(\d+)”) do? A. It extracts one or more
digits from a string.

Q32. What does pd.to_numeric(errors=“coerce”) do? A. It converts values

Q33. What does quantile(0.25) return? A. It returns the 25th percentile.

KEY CONCEPTS - Data aggregation summarizes records using sum, mean,
count and other functions. - Sales amount is calculated as quantity
multiplied by price. - groupby() groups records by selected columns. -
agg() performs one or more aggregation operations. - pivot_table()
summarizes data in a row-and-column format. - idxmax() returns the label
associated with the maximum value. - Monthly aggregation identifies
sales trends over time. - Bar, pie and line charts help compare sales
summaries.

FINAL QUICK REVISION: COMMON PYTHON AND DATA ANALYSIS QUESTIONS
============================================================

Q1. What is the difference between a Series and a DataFrame? A. A Series
is one-dimensional. A DataFrame is two-dimensional and has rows and
columns.

Q2. What is NaN? A. NaN means Not a Number and is commonly used to
represent missing numerical values.

Q3. What is NaT? A. NaT means Not a Time and represents missing datetime
values.

Q4. What is the difference between axis=0 and axis=1? A. axis=0 refers
to rows; axis=1 refers to columns.

Q5. What does inplace=True mean? A. It modifies the original DataFrame
instead of returning a separate modified DataFrame.

Q6. What is the difference between dropna() and fillna()? A. dropna()
removes records or columns with missing values. fillna() replaces
missing values.

Q7. What is the difference between mean, median and mode? A. Mean is the
average, median is the middle value, and mode is the most frequent
value.

Q8. What is the difference between object and int64? A. object commonly
stores text or mixed values; int64 stores integers.

Q9. What is the difference between fit(), transform() and
fit_transform()? A. fit() learns parameters. transform() applies learned
parameters. fit_transform() learns and applies the transformation.

Q10. What is overfitting? A. Overfitting occurs when a model learns the
training data too closely and performs poorly on unseen data.

Q11. What is supervised learning? A. It is machine learning using
labelled data, where the target output is known during training.

Q12. What is unsupervised learning? A. It is machine learning that finds
patterns in data without target labels.

Q13. What is regression? A. Regression predicts a continuous numerical
value.

Q14. What is classification? A. Classification predicts a category or
class label.

Q15. What is the difference between correlation and causation? A.
Correlation describes association between variables. Causation means one
variable directly produces a change in another.

Q16. What is an outlier? A. An observation that is unusually far from
the majority of the data.

Q17. What is standardization? A. It transforms numerical features to a
common scale, often with mean 0 and standard deviation 1.

Q18. What is one-hot encoding? A. It converts categories into separate
binary columns.

Q19. What is data leakage? A. It occurs when information that should be
unavailable during training influences model development or evaluation.

Q20. Why do we visualize data? A. Visualization helps identify trends,
patterns, differences, distributions and possible outliers.
